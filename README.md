The Library Management System is a software application developed to automate and manage the daily operations of a library efficiently. The system helps librarians maintain records of books, manage member details, and handle the issue and return of books in an organized manner.

This project reduces manual paperwork and improves accuracy, speed, and data management within the library.

 Add, update, delete, and view book details

 Add and manage member information

 Issue and return books

 Search books by title or author

 Maintain records of transactions
